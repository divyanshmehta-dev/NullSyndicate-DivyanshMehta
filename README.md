# VIT Bhopal:–Smart Campus Navigator🗺️

An interactive, single-page website that helps students and visitors in the VIT Bhopal campus — find buildings, sports grounds, and amenities on a map, get walking times, and ask a built-in chatbot for directions.

## 🚀 Features:-

- **Interactive Campus Map** – Showing all major campus locations as glowing pins.
- **Search with Autocomplete** – Instantly search for any location by name, category or landmark description.
- **Category Filters** – One-tap filter pills to view only academic blocks, food courts, hostels, sports facilities, or amenities.
- **Place Details Panel** – Click any pin or search result to see its name, category, description, and walking time from Hostels and AB-1.
- **Campus Assistant Chatbot** – A lightweight keyword-matching chatbot that answers questions like "where can I get food?" or "how do I reach the library?"
- **Light/Dark Mode** – Toggle between a light theme and a dark theme.
- **Fully Responsive Single File** – The entire website runs from one `.html` file — no in-build tools or server required.

## 🛠️ Tech Stack:-

- **HTML/CSS** – Layout, theming, animations
- **JavaScript** – App logic, search, filtering, chatbot engine
- **No frameworks/no backend** – Runs entirely in the browser
