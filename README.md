# VIT Bhopal – Smart Campus Navigator 🗺️

An interactive, single-page web app that helps students and visitors navigate the VIT Bhopal campus — find buildings, hostels, sports grounds, and amenities on a live map, get walking times, and ask a built-in chatbot for directions.

## 🚀 Features

- **Interactive Campus Map** – Built with Leaflet.js, showing all major campus locations as color-coded glowing pins (academic, food, hostel, sports, amenity).
- **Search with Autocomplete** – Instantly search for any location by name, category, or landmark description.
- **Category Filters** – One-tap filter pills to view only academic blocks, food courts, hostels, sports facilities, or amenities.
- **Place Details Panel** – Click any pin or search result to see its name, category, description, and walking time from Hostels and AB-1.
- **Campus Assistant Chatbot** – A lightweight keyword-matching chatbot that answers questions like "where can I get food?" or "how do I reach the library?"
- **Light / Dark Mode** – Toggle between a light theme and a neon "radium" dark theme.
- **Campus Gallery Slideshow** – A built-in image slideshow to showcase the campus.
- **Fully Responsive Single File** – The entire app (HTML, CSS, JS) runs from one `.html` file — no build tools or server required.

## 🛠️ Tech Stack

- **HTML5 / CSS3** – Layout, theming (CSS variables), animations
- **Vanilla JavaScript** – App logic, search, filtering, chatbot engine
- **No frameworks / no backend** – Runs entirely in the browser
